## Unity Developer | 2D/3D Game Development | C# | Tilemaps | Combat Systems | Gameplay Programming | Performance Optimization

Я Unity (C#) Developer с опытом разработки 2D и 3D-игр, где каждая механика – это инженерная задача, требующая продуманной архитектуры и точной настройки.
За время работы реализовал платформер Snot in a Spacesuit, где добился отзывчивого управления: плавное движение, ускоренное падение и адаптивный прыжок с изменяемой гравитацией через Physics2D.gravity. Настроил боевую систему с AI-врагами и отталкиванием при ударе, обеспечив тактильную точность взаимодействий. Оптимизировал сборку WebGL, что позволило запускать игру в браузере без установки.

В Save the Village разработал систему управления ресурсами: крестьяне собирают урожай, футмены расходуют его на защиту деревни, а игрок в реальном времени видит динамику ресурсов через UI. Настроил таймеры, балансировав сложность, и интегрировал звуковое сопровождение, делая процесс глубже и атмосфернее.

В Zombie Shooter 3D работал над боевой системой, где персонаж свободно переключается между ближним и дальним боем без конфликтов анимаций. Реализовал таргетинг через ПКМ, добавил динамическую камеру (Cinemachine) и внедрил Zenject для удобной организации зависимостей.

В 2D Top-Down Pixel Action-RPG создал мобильное управление с виртуальным джойстиком, систему инвентаря с Drag & Drop, а также AI-врагов разного типа, включая стрельбу с корректными столкновениями (Physics2D.IgnoreCollision). Применял ООП, SOLID, использовал Singleton для управления инвентарем и корутины для анимации атак.

Мой прошлый опыт Project Producer в продакшн-студии научил меня не просто писать код, а видеть продукт в целом: выстраивать пайплайн разработки, оценивать риски, балансировать ресурсы и эффективно работать в команде. Это позволяет мне не только реализовывать игровые механики, но и подходить к разработке стратегически, создавая цельные и качественные игровые проекты.
